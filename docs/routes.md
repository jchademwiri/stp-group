# Sithembe Website URL & Metadata Routing Map

This document defines the website's canonical URL structures, routing definitions, navigation hierarchy, and SEO metadata requirements for the Plant Hire and Services expansion.

---

## 1. Canonical URL Map & Navigation Structure

All paths are relative to the root URL: `https://sithembe.co.za` (or alternate deployment domains).

| Route / Path | Hierarchy | Page Type | Primary User Flow / Action Goal |
| :--- | :--- | :--- | :--- |
| `/` | Root | Home Page (Coming Soon / Hub) | Direct visitors to key segments |
| `/plant-hire` | Parent | Fleet Landing / Directory | Browse list of fleet machinery -> click `/plant-hire/[slug]` |
| `/plant-hire/[slug]` | Child | Dynamic Equipment Details | Review specs -> Submit Quote Form / Click WhatsApp |
| `/services/grass-cutting` | Child | Grass Cutting / Landscaping | Estimate acreage costs -> Submit Lead form |
