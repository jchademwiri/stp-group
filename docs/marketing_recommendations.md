## 1. MVP Phase (Phase 1 - Launch ASAP)

### A. Floating WhatsApp Chat Widget (Pre-built CTA)
*   **Recommendation**: Place a static green WhatsApp button in the bottom right corner.
*   **Reasoning**: Heavy machinery rentals and clearing services in South Africa see significant drop-offs in long forms. Quick messaging creates a fast entry point for quotes.
*   **Implementation**: Create a lightweight component fixed to the screen linking directly to dispatch WhatsApp with pre-filled message text templates.

### B. Safety & Operator Credential Text
*   **Recommendation**: Add immediate visual callouts in the page margins and headers:
    *   *“Rates include a TETA/SAMA certified operator.”*
    *   *“Fully insured for public liability.”*
    *   *“COIDA compliant.”*
*   **Reasoning**: Instantly overcomes liability concerns of renting heavy earthmoving/transport units.

### C. CIDB Grading Visuals
*   **Recommendation**: Display Sithembe's active CIDB grading badges (6 CE, 6 EP, 6 SH) prominently in headers/footers to build enterprise-level trust.

---

## 2. Post-MVP Phase (Phase 2 - Iterative Enhancements)

### A. Interactive Area Cost Estimator (for Grass Cutting)
*   **Recommendation**: An interactive widget letting users slide an input of their plot size (e.g., from $100m^2$ to $10ha$) and select service types to display an approximate quote estimation on-screen, linking to booking form pre-fills.

### B. Live Fleet Availability Indicators
*   **Recommendation**: Add green/amber/red status badges to individual equipment pages showing if the machine is free for immediate dispatch or pre-booked, boosting transparency.

### C. Before/After Split Comparison Slider
*   **Recommendation**: An interactive touch-based comparison slider on the Grass Cutting page, showing site reclamation work visually.

### D. Structured Schema Markup
*   **Recommendation**: Dynamically inject JSON-LD schemas (`Product` and `RentAction`) on plant detail pages to display listing data directly inside search engine result snips.
